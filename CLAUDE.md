# CLAUDE.md — контекст проекта для Claude Code

R-проект с Python-шагом эмбеддингов: кодировка открытых ответов опроса.
Подробности для человека — в README.md; здесь — то, что нужно знать агенту.

## Данные

В `data/` и `map/out/` лежат ответы респондентов. Никогда не коммитить их и не добавлять
в код примеры ответов. Перед `git add` проверять `git status`; `.gitignore` не отменять.

## Команды

```bash
Rscript install_packages.R    # установка пакетов (долго: сборка из исходников на Windows)
Rscript run_pipeline.R        # база .sav -> леммы -> векторы -> данные приложения
Rscript map/01_cluster.R      # разбивка на теги под сегменты, печатает показатели
Rscript map/02_export.R       # раскладки карты, map/out/data.json и summary.txt
python map/build.py           # собирает map/out/map.html
Rscript run_app.R             # Shiny-приложение (блокирующий процесс)
```

Проверка синтаксиса после правок: `Rscript -e "invisible(parse('app.R'))"`.

## Архитектура

- `pipeline/00_config.R` — единственное место всех настроек; его source-ят пайплайн, app.R и map/.
  Новые константы добавлять сюда. Перед первым запуском там нужно указать `RAW_SAV_PATH`,
  `TEXT_VAR` и `SEGMENT_VAR`.
- Скрипты запускаются из корня проекта. Шаги общаются через файлы в `data/` и `map/out/`.
- `EMBEDDING_SOURCE`: "llm" (по умолчанию, нужен Python с sentence-transformers и pandas)
  или "word2vec". После смены нужен пересчёт 03b/03 + 04, старые теги пересоздать.
- Теги приложения хранятся в CSV в `data/`; пайплайн их не трогает, но после пересчёта
  модели старые теги могут перестать соответствовать векторам (предупреждать пользователя).
- Карта автотегов: названия тегов берутся из `map/out/names.json` (порядок = номера TOP и MID
  в `map/out/summary.txt`), иначе подписи собираются из общих слов. Названия давать, прочитав
  сводку. Номера скоплений меняются после повторного `01_cluster.R` с другими настройками.

## Грабли

- Установка пакетов: если запущен R-процесс, DLL заблокированы и install.packages падает с
  "cannot remove earlier installation". Сначала остановить свои Rscript-процессы.
- В load_tags_log() типы столбцов заданы явно (col_types) — не убирать, иначе bind_rows падает.
- Модель udpipe для русского качается в `data/udpipe_model/` при первом запуске 02_preprocess.R.
- Лемматизация нескольких тысяч фраз идёт минуты; запускать пересчёт в фоне.
- Частица "не" склеивается со следующим словом ("не тратить" -> лемма "не_тратить").
- Перед запуском сервера проверять, что порт свободен: чужой сервер на том же порту
  отдаст чужие файлы.
